## 一、接线

| 功放引脚 | 接到 | 说明 |
|---|---|---|
| VIN | **5V** | 不要走面包板电源轨（触点只扛 1A，峰值会压降重启） |
| GND | GND | |
| BCLK | GPIO15 | |
| LRC | GPIO16 | |
| DIN | GPIO17 | |
| **SD** | **3V3** | 悬空 = 静音 |
| GAIN | 悬空 | 9dB；接 GND=15dB；接 VDD=3dB |
| `+` / `−` | 喇叭两根线 | **都不能接地** |

喇叭只接**一个**（单声道功放，两个 8Ω 并联变 4Ω 会过热）。

## 二、六个坑

### 坑 1：SD 脚悬空 → 只有上电"嘣"一声，之后全哑

- **现象**：代码跑通，串口正常，喇叭只在开机瞬间响一下
- **原因**：MAX98357 的 SD（shutdown）脚悬空时电平不确定，被判定为关断
- **修法**：SD 接 3V3
- **判据**：万用表量 SD 对 GND，应该 3.3V

### 坑 2：喇叭任一端接 GND → 烧功放

- **原因**：MAX98357 是 **BTL 桥接输出**，`+` 和 `−` 都是活输出，**都不是地**。任一端接地 = 短路输出级
- **修法**：喇叭两根线只接 `+` 和 `−`
- **判据**：喇叭 `−` 到 GND 用万用表量，**必须不通（∞）**

### 坑 3：照抄网上的 I2S 代码编译不过

- **现象**：`driver/i2s.h: No such file`
- **原因**：esp32 core 3.x 重写了 I2S 驱动，2.x 的 API 全废
- **修法**：用 `driver/i2s_std.h` + `i2s_new_channel()` + `i2s_std_config_t`
- **判据**：3.x 里 `i2s_driver_install` 不存在

### 坑 4：播放速度翻倍、音调变高

- **原因**：I2S 配的是 **STEREO**，送 mono 数据会被当成左右声道交替读
- **修法**：每个样本写两次

```cpp
buf[k*2]     = v;   // 左
buf[k*2+1]   = v;   // 右
```

### 坑 5：BOOT 按键按了没反应（或者一直响）

- **原因**：GPIO0 没设 `INPUT_PULLUP`，浮空输入读数不确定
- **修法**：

```cpp
pinMode(0, INPUT_PULLUP);   // setup 里
if (digitalRead(0) == LOW) { ... }   // 按下 = 接 GND = LOW
```

- **注意**：GPIO0 是 **strapping 脚**，上电那一刻如果按着会进下载模式，不跑程序

### 坑 6：喇叭线在螺丝端子里松

- **原因**：多股细铜丝比端子孔细太多，螺丝压不住
- **修法**：剥 10mm → **对折成双股** → 手指捻紧 → 插到底 → 螺丝拧死
- **注意**：散开的铜丝可能碰到旁边端子造成短路

## 三、人声从哪来

**不用找素材，让 Windows 自己说：**

```powershell
Add-Type -AssemblyName System.Speech
$s = New-Object System.Speech.Synthesis.SpeechSynthesizer
$s.SelectVoice("Microsoft Huihui Desktop")   # 中文女声
$fmt = New-Object System.Speech.AudioFormat.SpeechAudioFormatInfo(
    22050,
    [System.Speech.AudioFormat.AudioBitsPerSample]::Sixteen,
    [System.Speech.AudioFormat.AudioChannel]::Mono)
$s.SetOutputToWaveFile("D:\zz187\Arduino\audio_src\tts_hello.wav", $fmt)
$s.Speak("你好，我是张正，这是我的第一个语音设备。")
$s.Dispose()
```

然后 `wav2h.py` 转成 C 数组。

**这就是 TTS 输出的最小闭环**，以后接上大模型，回答就从这里出来。

## 四、不用耳朵也能验证音频对不对

`D:\zz187\Arduino\audio_src\audio_check.py`

```bash
python audio_check.py 录音.wav
```

输出：基频、谐波失真、削顶样本数、信噪比、波形图、频谱图、能量图。

### 判据

| 信号类型 | 频谱特征 | 波形特征 |
|---|---|---|
| **正弦测试音** | **一根尖线**，谐波 <1% | 等幅、规则 |
| **人声** | **一片宽带**（500–1500Hz 共振峰，延伸到 8kHz） | 一个个包络鼓包（音节） |
| **失真/削顶** | 谐波比 >5%，出现奇数倍峰 | 波峰被削平 |

### 实测数据

| 项目 | 第一次（循环） | 第二次（按键） | 第三次（人声） |
|---|---|---|---|
| 基频 | 887.5 Hz | **880.0 Hz** | 宽带（共振峰 900Hz） |
| 谐波 | 0.1% | 0.81–1.55% | — |
| 信噪比 | — | **72.7 dB** | 41 dB |
| 削顶 | 0 | 0 | 0 |

> **887.5 vs 880 的差值来自手机录音时钟，不是板子问题**——第二次精确命中 880.0 证明了这点。

## 五、音频流水线（换内容零改代码）

```
任意音频 ──ffmpeg──▶ 22050Hz/mono/16bit WAV ──wav2h.py──▶ audio.h
```

**一键工具**：`D:\zz187\Arduino\换音频.bat`（双击 → 选文件 → 自动生成 audio.h → 回 IDE 点上传）

**flash 预算**（app 分区 3MB，开屏图占 400KB）：

| 时长 | 22050Hz | 11025Hz | 8000Hz 8bit |
|---|---|---|---|
| 5 秒 | 220 KB | 110 KB | 40 KB |
| 30 秒 | 1.3 MB | 661 KB | 240 KB |
| 60 秒 | 2.6 MB ❌ | 1.3 MB | 480 KB |
| 3 分钟 | 放不下 | 4 MB ❌ | 1.4 MB ✅ |

**结论**：app 分区只够放 35–40 秒人声。**想放整首歌必须用 FATFS 分区（9.9MB）**。
